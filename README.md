# 🎸 GuitarSkills

An advanced, agentic AI-powered guitar learning companion, tone-dialing assistant, and programmatic tablature validation engine. 

Designed to bridge the gap between advanced music theory and physical fretboard muscle memory, **GuitarSkills** provides an exhaustive ecosystem for practice scheduling, chord exploration, verified playability, and hardware tone matching.

---

## 🌟 Key Features

### 1. 🎛️ The Tone Vault & Advisor
A robust tone database and signal-chain advisory engine tailored for Logic Pro, physical preamp systems (like the Tone King Imperial Preamp), and modeling captures.
* **Interactive Dashboard**: A custom-designed, fully searchable, and responsive web interface (`tone-advisor/tone-viewer.html`) with advanced filters for pickup configurations (Single-Coil, Humbucker, P-90), genres/styles, specific guitars, and amplifiers.
* **Programmatic Compilation**: Built via a Python parser (`tone-advisor/generate_tone_viewer.py`) that translates human-readable Markdown tone profiles into a lightweight, elegant single-page application.
* **Strict Gain-Staging Standards**: Anchored by rigorous gain-staging and calibration specifications (`tone-advisor/TONEPRINT_GUIDELINES.md`) to maintain audio fidelity across diverse gear.

### 2. 🎼 Strict Tablature Verification Pipeline
One of the most powerful features of GuitarSkills is its zero-tolerance policy for unplayable tabs. Every exercise or etude generated by the coaching agent must pass through a strict programmatic sanity check:
* **String-Fret Validity**: Matches notes to standard or custom tunings.
* **Physical Stretch Checking**: Programmatically rejects physical impossibilities (e.g., finger stretches exceeding realistic fret ranges).
* **Logical Finger Crossover**: Validates transition logic for smooth, playable, and realistic hand positioning.
* **Verification Pipeline**:
  ```bash
  python3 scripts/build_tab.py --inline '<json_spec>' > /tmp/exercise.tab
  python3 scripts/verify_tab.py /tmp/exercise.tab
  ```
  Only tabs that exit with code `0` are ever presented to the player.

### 3. 📐 Programmatic Chord Voicing Library
An exhaustive Python-based chord theory library (`chord-library/`) allowing instant CLI queries of voicings, shapes, fingerings, drop-chords, and inversions.
* Query voicings by name (e.g. `C7`, `Am9`, `Gm7b5`).
* Analyze voice leading and interval structures programmatically to translate advanced vocal/arranging instincts onto the fretboard.

### 4. 📈 Structured Coaching & Practice Library
Generates and archives highly structured practice sessions, daily etudes, and deep-dives:
* **Theory + Muscle Memory**: Bridges the gap between hearing/reading music and physical dexterity.
* **Targeted Daily Etudes**: Musical practice concepts accompanied by 100% verified, playable ASCII tab.
* **Autonomous Standard Studies**: Comprehensive breakdowns of jazz standards, complete with fingerings, harmonic explanations, and history.
* **Integrated Spotify Playlists**: Matches practice sessions with curated real-world reference recordings and play-along tracks.

## 🚀 Getting Started

### Prerequisites
* Python 3.8+
* Basic terminal access to run compilation and tab scripts

### Building the Tone Vault Web Viewer
Whenever you modify, add, or update any tone profiles in `tones/`, rebuild the beautiful web dashboard with:
```bash
python3 tone-advisor/generate_tone_viewer.py --build-only
```
This parses all Markdown profiles, checks their frontmatter, rebuilds `tones/INDEX.md`, and compiles `tone-advisor/tone-viewer.html`.

### Generating and Verifying a Tab
To programmatically generate and verify a guitar etude tab:
```bash
# Generate the tab spec
python3 scripts/build_tab.py --inline '{"tuning": "EADGBE", "frets": [null, 3, 2, 0, 1, 0]}' > /tmp/exercise.tab

# Run the strict physical-playability validation checks
python3 scripts/verify_tab.py /tmp/exercise.tab
```
