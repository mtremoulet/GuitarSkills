# Quarantined Presets

This directory holds plugin and DAW presets that have been removed from active plugin directories when toneprints are set to `status: archived` or when unreferenced/legacy experimental presets are cleaned up.

Presets are organized in sub-folders mirroring their original system or user locations (relative to the user home or system root), allowing them to be inspected or restored at any time without destructive deletion.
