# Common Chord Progressions by Genre

Reference for generating practice etudes. Each progression includes Roman numeral
analysis, common keys for guitar, and typical tempo/feel.

---

## Jazz

### ii-V-I (the backbone)
```
| ii7  | V7   | Imaj7 |     |
  Dm7    G7     Cmaj7         (in C)
  Am7    D7     Gmaj7         (in G)
  Em7    A7     Dmaj7         (in D)
```
Tempo: 100-200 BPM | Feel: swing
Usage: Nearly every jazz standard. Core vocabulary.

### I-vi-ii-V (turnaround)
```
| Imaj7 | vi7  | ii7  | V7  |
  Cmaj7   Am7    Dm7    G7    (in C)
  Fmaj7   Dm7    Gm7    C7    (in F)
```
Tempo: 120-180 BPM | Feel: swing
Usage: Last 2 bars of many standards, "Rhythm Changes" bridge.

### iii-vi-ii-V (extended turnaround)
```
| iii7 | vi7  | ii7  | V7  |
  Em7    Am7    Dm7    G7    (in C)
```

### Minor ii-V-i
```
| iiø7  | V7b9  | i7    |
  Dm7b5   G7b9    Cm7         (in Cm)
  Am7b5   D7b9    Gm7         (in Gm)
```

### Rhythm Changes (AABA, based on "I Got Rhythm")
```
A: | I   vi | ii  V | I   vi | ii  V |
B: | III7   | VI7   | II7    | V7    |
```

### Coltrane Changes (Giant Steps)
```
| Bmaj7 | D7  | Gmaj7 | Bb7 | Ebmaj7 | Am7 D7 |
```
Major thirds cycle. Advanced.

## Blues

### Basic 12-bar
```
| I7  | I7  | I7  | I7  |
| IV7 | IV7 | I7  | I7  |
| V7  | IV7 | I7  | V7  |
```
Common keys: E, A, G, D, C
Tempo: 80-140 BPM | Feel: shuffle or straight

### Quick-change 12-bar
```
| I7  | IV7 | I7  | I7  |
| IV7 | IV7 | I7  | I7  |
| V7  | IV7 | I7  | V7  |
```

### Jazz blues
```
| I7    | IV7   | I7    | #iv°7 |
| IV7   | #iv°7 | I7    | vi7   |
| ii7   | V7    | I7 vi7| ii7 V7|
```

### Minor blues
```
| i7  | i7  | i7  | i7  |
| iv7 | iv7 | i7  | i7  |
| v7  | iv7 | i7  | v7  |
```

## Neo-Soul / R&B

### Simple two-chord loops
```
| Imaj9  | ii9    |     (Dmaj9 → Em9)
| IVmaj9 | iii7   |     (Fmaj9 → Em7 in C)
| Imaj9  | bVII9  |     (Gmaj9 → F9)
```
Tempo: 65-85 BPM | Feel: laid back, behind the beat

### Four-chord neo-soul
```
| Imaj9 | iii7  | vi9  | IV9  |    (Gmaj9 Em7 Am9 C9)
| ii9   | V13   | Imaj9| IVmaj7#11 |
```

### Erykah Badu / D'Angelo style
```
| i9   | IV9   |     (minor tonic with major IV)
| Imaj9| #IVm7b5 | IV9 | iii7 |
```

## Rock / Pop

### I-V-vi-IV (the "pop" progression)
```
| I  | V  | vi | IV |
  C    G    Am   F     (in C)
  G    D    Em   C     (in G)
```
Tempo: 100-140 BPM | Huge number of pop/rock songs

### I-IV-V
```
| I  | IV | V  |
  A    D    E     (in A)
  E    A    B     (in E)
```
Classic rock & roll.

### vi-IV-I-V
```
| vi | IV | I  | V  |
  Am   F    C    G     (in C)
```
Slightly darker feel than I-V-vi-IV.

### I-bVII-IV (mixolydian rock)
```
| I  | bVII | IV |
  A    G      D       (in A)
  D    C      G       (in D)
```
Classic rock / southern rock. "Sweet Home Alabama" feel.

## Funk

### One-chord vamp
```
| I9 or I7#9 |  (E7#9 — Hendrix style)
```
Tempo: 95-120 BPM | All about the rhythm

### Two-chord funk
```
| I9   | IV9  |
| I7   | bVII7|
```

### James Brown style
```
| I7 | I7 | I7 | IV7 |  (one chord with hits)
```

## Ambient / Chill

### Suspended / modal loops
```
| Isus2  | Vsus4  |
| Iadd9  | IVadd9 |
| vi7    | IV     | I     | V    |  (with open voicings)
```
Tempo: 60-80 BPM | Feel: ethereal, lots of reverb

### Pedal tone progressions
```
Keep one note (usually the 5th or root) ringing through chord changes:
| Cadd9 | Em7 | G6  | Dsus4 |  (all with open B/E strings ringing)
```

## Country / Folk

### I-IV-V
```
| G  | C  | D  |    (in G)
| D  | G  | A  |    (in D)
```

### Nashville number system reminder
```
1 = I, 2 = ii, 3 = iii, 4 = IV, 5 = V, 6 = vi, 7 = vii°
```

### Common Nashville progressions
```
| 1  | 4  | 5  | 1  |
| 1  | 6  | 4  | 5  |
| 1  | 4  | 1  | 5  |
```

## Modal Progressions

### Dorian (minor with natural 6th)
```
| i7  | IV7 |     (Dm7 → G7 in D dorian)
```
Usage: Funk, jazz-funk, neo-soul. "So What" = D dorian.

### Mixolydian (major with b7)
```
| I7  | bVII |    (A7 → G in A mixolydian)
```
Usage: Rock, blues-rock, jam bands.

### Lydian (major with #4)
```
| Imaj7#11 | IImaj7 |    (Cmaj7#11 → Dmaj7)
```
Usage: Film scores, progressive rock, dream pop.

### Phrygian (minor with b2)
```
| i   | bII |     (Em → F in E phrygian)
```
Usage: Flamenco, metal, Middle Eastern-flavored music.
