# Flanger — Logic Pro

Source: logic-pro-mac-effects-user-guide.txt, lines 14384–14420

Add via: Modulation > Flanger in a channel strip Audio Effect plug-in menu.

---

## Overview

Works like Chorus but uses a significantly shorter delay time. Effect signal can be fed back to the delay line input. Creates a spacey or underwater quality in processed signals.

---

## Parameters

- **Sync button**: Synchronize modulation speed with project tempo. Choose note values with Rate knob.
- **Rate knob and field**: Frequency (speed) of the LFO
- **Intensity knob and field**: Modulation amount
- **Feedback knob and field**: Amount of effect signal routed back to input. Changes tonal color and makes sweeping effect more pronounced. Negative values invert the phase of the routed signal.
- **Mix knob and field**: Balance between dry and wet signals
