# Divided 11 Class A Boutique Guitar Amplifier — Nembrini Audio

Source: https://nembriniaudiodownload.blob.core.windows.net/installer/Divided11/Manual.pdf

---

## Overview

Emulation of the Divided by 13 CJ11 — an 11-watt Class A, tube-rectified boutique combo built by Fred Taccone. Rooted in 1950s tweed Fender DNA, voiced between a Fender tweed and a Vox AC15. Class A output tubes are always conducting, producing even, musical compression and sustain as the amp saturates. Tube rectifier adds sag and bloom on attack.

Single channel. Minimal controls. Maximum tone.

---

## Front Panel Controls

| Control | Function |
|---------|---------|
| POWER | Bypass the plugin — compare processed vs. unprocessed signal |
| BOOST | Overdrives the preamp section — pushes more gain for a thicker, more saturated tone |
| MASTER | Regulates the power amp section level. In a Class A context, Master also influences coloration and texture — it's not a neutral volume control |
| BASS | Low-frequency tone shaping |
| TREBLE | High-frequency tone shaping |
| VOLUME | Preamp gain level — sets how hard the preamp is driven. Directly controls preamp distortion amount and overall tone character |
| INPUT | Switches between input configurations simulating high and low gain inputs of a traditional amp. Significant impact on tone and gain structure |

## Cabinet — Impulse Loader Panel

Access by clicking the Cabinet/Impulse Loader button.

### Recording Chain Mode (3 buttons)
Selects one of three operating modes. Filters, Noise Gate, and Levels sections remain active in all three modes.

| Mode | Description |
|------|-------------|
| Cabinet | Uses the built-in cabinet/recording chain emulations |
| Impulse Loader | Uses loaded third-party IR files |
| Bypass | Bypasses cab/recording chain entirely — use with external IR loader or real power amp/speakers |

### Impulse Loader Mode

Load up to 3 third-party IR files simultaneously.

Per IR slot:
- **Empty**: unload current IR
- **Browse**: select a folder to preview available WAV files
- **Load**: load an impulse response file
- **Volume, Pan, Phase, Solo, Mute** controls for each IR

---

### Filters Section (always active, all modes)

Three named filter toggles — on/off only, not parameterized:

| Filter | Effect |
|--------|--------|
| Tight | Reduces low-frequency content to tighten the low range |
| Rumbling | Cuts low-frequency content to reduce boominess |
| Harsh | Reduces high-frequency content to soften overly bright tones |

### Noise Gate (always active)

| Control | Function |
|---------|---------|
| Power (red LED) | Activates the noise gate |
| Threshold | Level at which gate activates |
| Range | Amount of noise reduction |
| Gate | Speed of gate closing |

### Levels (always active)

| Control | Range | Function |
|---------|-------|---------|
| Input | −∞ to +12 dB | Signal level entering the plugin |
| Output | −∞ to +12 dB | Signal level exiting the plugin |
| Fix button | — | Keeps input level constant when switching presets |

## Tone Character Notes

- The Divided 11 sits between a Fender tweed and a Vox AC15 — sparkly and present, but with rounder and fuller low-mid character. Class A compression gives notes an alive, compressing quality.
- Unlike high-gain amps, the Divided 11 is nuanced and dynamic. Picking dynamics control the character significantly.
- **With humbuckers**: use Low input, pull Volume back slightly (4–5) for a controlled edge-of-breakup that cleans up with lighter picking.
- **Boost switch**: adds a gain stage — pushes into compressed, saturated territory. Good for leads and sustained melody. Leave off for dynamic blues/jazz tones.
- **THIRTEEN 1x12 GREEN** is the reference cab for this amp — the most accurate representation of the original hardware character.
- **VOICE 2x12 BLUE** (Vox Celestion Blue speakers) adds a chimey, bright, AC30-adjacent quality — more pronounced treble character.
- Pairs well with transparent overdrives (Clon Minotaur) as a boost, or Tone King Imperial feeding it cleanly for stacked boutique color.
