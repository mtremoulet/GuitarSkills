## Status

**This plug-in is no longer available for purchase.** It has been replaced by the [UAD Studio D Chorus](studio-d-chorus.md), which uses the **exact same algorithm**.

For all control documentation, see `docs/uad/studio-d-chorus.md`.

---

## Controls (identical to Studio D Chorus)

- **Dimension Mode 1–4**: Effect intensity. Mode 1 = most subtle, Mode 4 = maximum.
- **Multiple Buttons**: Shift-click to engage multiple mode buttons simultaneously.
- **Input Mode Switch**: STEREO (default, in) or MONO (stereo inputs summed to mono).
- **Power Switch**: ON (in) = active. OFF = bypass.
- **Power LED**: Illuminated when active.
- **Output Level**: LED meter showing output level.

## Background

1979 Roland Dimension D. Used by Peter Gabriel, Talking Heads, INXS. 1024-stage bucket-brigade circuit per channel. Spatial widening and subtle modulation — not an obvious chorus but a complex stereo enhancer.
