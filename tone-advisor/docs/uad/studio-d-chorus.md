# Studio D Chorus — UADx

Source: https://help.uaudio.com/hc/en-us/articles/7360582279828-Studio-D-Chorus-Manual

---

## Overview

Emulation of the Roland Dimension D (introduced 1979). Famous for spatialization and subtle modulation — "secret sauce" of Brian Eno, Stevie Ray Vaughan, and many others. Uses a 1024-stage bucket-brigade circuit per channel (most analog circuits use 512 or fewer). The effect enhances rather than transforms — not an obvious chorus, but a complex spatial widening that works on nearly any source.

**Note**: Not affiliated with Roland. Dimension D name identifies the hardware studied.

---

## Controls

### Dimension Mode (1–4)
Selects effect intensity. **Mode 1 = most subtle. Mode 4 = maximum intensity.**

Four push-buttons. Only one button active at a time in normal use.

### Multiple Buttons (Shift-click)
Shift-click to engage multiple Mode buttons simultaneously. Gives subtle sonic variations between the four main modes. Any combination is valid. "All buttons" mode (all four active) is a fifth distinct character.

### Input (STEREO / MONO)
Configures the input routing.
- **STEREO** (default, button in/darker): Stereo input passes normally.
- **MONO** (button out): Stereo inputs are summed to mono before processing. Useful for send/return configurations or sonic variation.

### Power (ON / OFF)
Overall bypass. ON (button in) = processing active. OFF (button out) = dry signal passes, DSP reduced.

### Power LED
Illuminated when plug-in is active.

### Output Meter
LED-style meter showing output level when processing is active.

## Character Notes

- Effect is subtle by design — widening, depth, and spatial interest without dramatically changing the sound
- Works on guitar, vocals, strings, synth pads, and buses
- On guitar: floating, shimmering textures without obvious pitch chorus warble
- On buses: can gel mixed elements (similar to gentle glue compression but in the spatial dimension)
- All-buttons mode is an extra, distinct character — darker and more enveloping than individual buttons
