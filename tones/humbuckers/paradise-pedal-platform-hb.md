# Paradise Pedal Platform (Humbucker Variant)

## Target Sound
Optimized for the thicker, warmer output of humbuckers. The **Enigmatic '82** (Dumble-style) is set to the **Silver** voice to provide the necessary top-end articulation and headroom that prevents humbuckers from becoming "muddy" when pushing pedals.

## Signal Chain

### 1. Amp: Enigmatic '82 — The Foundation

| Control | Setting | Purpose |
|---------|---------|---------|
| Voice | Silver | High-headroom, bright and articulate to balance HB warmth |
| Drive | 2.5 | Lowered for humbuckers to preserve clean headroom |
| Bass | 3.5 | **Cut for Humbuckers**: Prevents low-end flub when using drive pedals |
| Mid | 5.5 | Slight boost for vocal clarity |
| Treble | 6.5 | Pushed slightly for added snap |
| Presence | 6.0 | Top-end "air" and string definition |
| Master | 7.0 | High output for a "big" feel |


### 2. Cabinet & Room — Space
| Component | Setting | Purpose |
|-----------|---------|---------|
| Cabinet | 1x12 EV12 | Flat, wide-range response |
| Room | Studio A | Small, controlled space |
| Room Mix | 12% | Subtly less mix to keep the humbucker focus tight |

#### Amp Settings


#### Pre-FX Option: Gold Overdrive

| Control | Setting | Purpose |
|---------|---------|---------|
| Pedal | **Gold Overdrive** | Transparent clean boost on hand |
| State | **Disabled** (Off) | Bypass by default; engage for clean solo boost or pushing front end |
| Gain | **0.0** | Zero added distortion; pure clean boost |
| Output | **7.5** | Pushes front end of amp for singing sustain and level lift |
| Treble | **4.5** | Slightly rounded high end for smooth boost response |

### 3. Pre-FX Pedal Menu (Humbucker Voiced)
*Turn only **ONE** on at a time.*

#### Option A: Nashville OD (HB)
*   **Drive**: 3.5 (Humbuckers push the input harder)
*   **Tone**: 6.0 (Added clarity)
*   **Level**: 5.5

#### Option B: TS Overdrive (HB)
*   **Drive**: 3.0
*   **Tone**: 6.0 (Compensate for HB mid-thickness)
*   **Level**: 6.0
